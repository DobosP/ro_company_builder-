# Knowledge Base — Romania (Common Info)

Verified, dated facts an AI or founder needs to form and run a company in Romania. This is the "common info" pillar; the methodology pillar is in [`../framework/`](../framework/).

> ⚠️ **Not legal, tax, or financial advice.** Facts verified **2026-05**. Romanian fiscal and corporate law changes frequently (major reforms in 2025–2026). **Re-verify with ONRC/ANAF or a licensed professional before acting.** Every figure is sourced in [`sources.md`](sources.md).

## How facts are maintained
- Each figure carries an inline citation like [[S6]](sources.md#s6) pointing to a dated source entry.
- When a fact is updated, update both the doc **and** its `sources.md` entry's `verified` date.
- If a fact can't be verified, mark it `[TODO: verify]` rather than guessing.
