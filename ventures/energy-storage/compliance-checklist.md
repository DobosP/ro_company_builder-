# Compliance Checklist — Hybrid Solar-plus-Storage (Romania)

> Hybrid-specific, derived from [research notes](research/research-notes.md) and [`../../knowledge/`](../../knowledge/). Not legal advice — confirm with ANRE / a lawyer. [E#] → [sources](research/sources.md).

## Formation (ONRC)
- [ ] SRL (and/or per-site **SPV**) registered; CAEN **3512** (solar production) + **3516** (storage) + **3515** (trading) [E35](research/sources.md#e35)
- [ ] CUI + J-number — see [company-formation](../../knowledge/company-formation.md)

## Grid connection (the gating step — Order 20/2025)
- [ ] Connection request filed as a **complete file** (for prioritization) [E14](research/sources.md#e14)
- [ ] **Solution study** received; **financial guarantee** posted in time (else lapses) [E14](research/sources.md#e14)
- [ ] **ATR** obtained; note any **operational limitation** [E14](research/sources.md#e14)
- [ ] Guarantees budgeted: **€20k/MW** + **€30k/MW** + **20% of connection tariff** [E13](research/sources.md#e13)
- [ ] Connection sized for the **shared** hybrid export (battery + solar) [E28](research/sources.md#e28)

## ANRE authorizations
- [ ] **Storage:** establishment authorization > 1 MW; operating licence before COD [E13](research/sources.md#e13) [E15](research/sources.md#e15)
- [ ] **Solar:** **setting-up authorization > 1 MW** (Order 6/2025; ≤1 MW exempt) [E26](research/sources.md#e26)

## Solar land & siting
- [ ] Land class checked — **avoid Class I–III** (needs Ministry-of-Agriculture conversion) [E27](research/sources.md#e27)
- [ ] If **<50 ha on Class III/IV/V** extra-muros land → **no PUZ** required [E27](research/sources.md#e27)
- [ ] Urbanism certificate; consider **agrivoltaic** grassland dual-use (MADR Order 4/2025) [E27](research/sources.md#e27)
- [ ] Land control (lease/option) secured

## Construction & environment
- [ ] Building permit (*autorizație de construire*) for battery + solar [E13](research/sources.md#e13)
- [ ] Environmental sign-off / EIA screening

## Market participation
- [ ] Registration to trade on **OPCOM** (DAM/IDM) / via a Balancing Responsible Party or optimiser [E12](research/sources.md#e12)
- [ ] Metering & telemetry to Transelectrica for balancing [E11](research/sources.md#e11)

## Fiscal & reporting (standard)
- [ ] ANAF registration; **CIT** regime; **VAT** registration (recover CAPEX VAT)
- [ ] e-Factura / SAF-T / (e-Transport if moving equipment) — see [regulatory-compliance](../../knowledge/regulatory-compliance.md)

## Funding compliance — pick ONE route for the battery
- [ ] **Standalone** scheme (CISAF) — entity registered with ONRC before first aid payment [E2](research/sources.md#e2)
- [ ] **Co-located** behind-the-meter — **≥75%** RES-absorption rule; **≤€10M**/enterprise [E3](research/sources.md#e3)
- [ ] Confirmed the two routes are not combinable for the same asset
