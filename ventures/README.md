# Ventures

One folder per concrete venture. **This pass only scaffolds** — deep research happens in later sessions.

## How to add a venture
1. Copy [`_template/`](_template/) to `ventures/<slug>/` (e.g. `ventures/energy-storage/`).
2. Work through [`../framework/hard-questions.md`](../framework/hard-questions.md).
3. Fill the [`../templates/`](../templates/) (brief, business plan, financials, market, compliance, risks, decisions).
4. Pull venture-specific research and cite it.
5. Score with [`../framework/evaluation-rubric.md`](../framework/evaluation-rubric.md).
