## 2026-05-29 — finsim proves it: phase it (self-consumption base first), don't build all at once
- **All-at-once** (solar+storage+pumps+lakes+greenhouse+aquaculture, €5M CAPEX, €2.23M stacked grants): **IRR 0.5%, NPV −€1.75M, financing gap −€1.17M** → unviable as a single build. [finsim-report.md](finsim-report.md)
- **Phase 1 only** (solar+storage+pumps+greenhouse, €3.4M CAPEX, €1.4M grants, €1.5M equity): **IRR 10.0%, NPV +€6k, no gap, payback 2034** → fundable. [finsim-phase1-report.md](finsim-phase1-report.md)
- **Lesson:** the self-consumption energy+water+greenhouse base works; **aquaculture/algae must be a later, separately-funded (EMFAF) phase**, not bolted on up front. DSCR is tight in the greenhouse ramp → seek a **debt grace period**.
- **Decision:** adopt the **4-phase plan** (energy/water → greenhouse → fish/algae → processing/circular); structure as **HoldCo + SPVs** to stack funds without double-funding. See [funding-stack.md](funding-stack.md), [system-design](research/system-design.md).

## 2026-05-29 — Created the integrated venture; core idea = stack a different fund per module
- Combines [energy-storage](../energy-storage/) (solar+storage+circular) and [agriculture-irrigation](../agriculture-irrigation/) (greenhouse/irrigation/processing) and adds **fish + algae + funding-stacking**.
- Each module → its own fund: AFIR (greenhouse/irrigation/processing), **EMFAF ≤70%** (fish), Modernisation Fund (battery), agrivoltaics Law 254/2022 (solar), LIFE/Horizon (algae). [I1](research/sources.md#i1) [I7](research/sources.md#i7)
- **Cheaper/secondhand/new-tech levers:** floating PV + second-life panels/batteries; MPPT solar pumps (>99%); flat-panel photobioreactors (3–4× cheaper algae); polytunnel→smart greenhouse. [I5](research/sources.md#i5) [I6](research/sources.md#i6)
- **Honest caveats:** aquaponics profitable >1,000 m² (~2 yrs); "free" fertiliser costs 7–88× inorganic/nutrient; deep-water needs Apele Române permit. [I2](research/sources.md#i2) [I3](research/sources.md#i3)
