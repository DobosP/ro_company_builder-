## Snapshot
- **What:** a self-sufficient agri-energy "ecosystem" — generate own power (solar+storage), pump own water (solar boreholes → lakes), grow own inputs (fish effluent + algae → natural fertiliser), produce high-value food (smart greenhouses), sell the surplus.
- **Why now:** every loop maps to a **live, generous fund** — AFIR (greenhouse/irrigation/processing), **EMFAF** (fish, ≤70%), Modernisation Fund (battery), agrivoltaics law (solar) — so the system can be **majority grant-funded** by stacking. [I1](research/sources.md#i1) [I7](research/sources.md#i7)
- **Hard truths:** operationally **very complex** (must phase it); aquaponics profitable only at scale (>1,000 m²); "free" fertiliser isn't free; needs a water-abstraction permit. [I2](research/sources.md#i2) [I3](research/sources.md#i3)
- **Stage:** ☑ Idea ☑ Validate (desk) ☐ Model ☐ Form ☐ Operate — see [lifecycle](../../framework/venture-lifecycle.md)
- **Rubric score:** see [hard-questions.md](hard-questions.md) / decision notes.

## The structuring insight
**One holding company + per-module SPVs**, each SPV applying to its own fund (no cost double-funded). Phase the build to match funding windows and de-risk operations. See [funding-stack.md](funding-stack.md).
